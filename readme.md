# VoiceKhata 🎙️

VoiceKhata is a simple voice-based **Khata management demo** for recording customer credit and payment transactions using Hindi/English voice input.

## Features

* Voice and manual transaction entry
* Hindi/English speech recognition using the browser
* Automatic transaction extraction
* Customer management
* Credit and payment tracking
* Customer transaction history
* Sales reports
* Voice/text Khata assistant

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, FastAPI
* **Database:** SQLAlchemy + SQLite
* **Speech:** Browser Web Speech API
* **AI:** OpenAI API

## Important

VoiceKhata is currently a **demo/MVP**. The project is intended to demonstrate voice-based Khata management and is not a production accounting system.
